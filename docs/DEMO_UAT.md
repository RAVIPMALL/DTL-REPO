# v0.8 Demo/UAT

Android starts with Demo Employee or Admin Preview.

Employee credentials: `demo.employee` / `DTL@Demo2026`
Admin credentials: `demo.admin` / `DTL@Admin2026`

Interactive employee areas: salary details, leave form, document search/filter, notification read state, APAR editing/submission and profile.

Interactive admin areas: registration approval counter, leave approval counter, document publishing counter, notification composition/broadcast and APAR monitoring.

Web admin: `cd admin && npm install && npm run dev`

All data is synthetic. Disable Demo Mode and replace credentials before production.
